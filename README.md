# Superstore SQL Analysis

This project contains SQL queries and analysis scripts for exploring a superstore sales dataset.

## Dataset

The data used in this project is sourced from Kaggle:

- Sales Forecasting dataset by Rohit Sahoo
- URL: https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting

## Attribution

This dataset is provided on Kaggle and is used here for educational and analytical purposes. Please refer to the original Kaggle dataset page for licensing, usage terms, and dataset details.

## Project Contents

- SQL queries for exploring and analyzing sales data
- Dataset file(s) used in the analysis
- Answers and practice questions for structured SQL analysis

## Notes

This repository is intended for learning, SQL practice, and business data analysis using the provided sales forecasting dataset.
